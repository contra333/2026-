## 4. 이번에 추가로 학습할 모델

`통계학회_포스터_실험계획.md`에는 full/practical/minimal LR-WD grid 후보가 모두 들어 있다. 이 후보들은 역할이 다르다.

| Grid type | 역할 | 이번 포스터 우선순위 |
|---|---|---|
| Existing 15-run seed0 grid | 이미 확보된 preliminary response surface | 이미 있음 |
| Selected 5 configs x seed1/2 | seed0-only 약점을 보완하고 `mean +/- std over 3 seeds`를 만들기 위한 핵심 반복 | 1순위 |
| Practical 27-run seed0 completion | LR-WD response surface를 더 촘촘히 보강하는 appendix/보조 근거 | 2순위 |
| Full 33-run seed0 completion | ICLR 본논문용 또는 충분한 GPU 여유가 있을 때의 reference grid | 3순위 |
| Practical/full grid x seed1/2 | 모든 cell의 seed 평균 | 이번 포스터 범위 밖 |

권장 결정:

```text
포스터 일정이 빠듯하면 selected 5 configs의 seed1/2 반복을 먼저 한다.
GPU 여유가 있으면 그 다음 practical 27-run의 빠진 seed0 cell을 보강한다.
새 seed0 cell이 좋은 후보로 나오더라도 seed1/2 반복이 없으면 main 3-seed table에는 넣지 않는다.
```

이유:

- 현재 포스터에서 가장 약한 점은 grid가 좁다는 점보다 `seed0-only`라는 점이다.
- 기존 15-run seed0 grid 안에도 ID-val 0.949-0.953대 Adam/AdamW 후보가 이미 있고, raw vs L2 detector gap이 충분히 보인다.
- practical grid를 먼저 완성하면 새 후보가 생길 수 있지만, 그 후보까지 seed1/seed2를 반복하지 못하면 포스터 main table은 다시 seed0-only가 된다.
- 따라서 통계학회 포스터의 main claim을 강화하려면 selected config 반복이 먼저다.

기본 실행안은 기존 seed0 15-run grid에서 포스터에 필요한 5개 config만 골라 seed1/seed2를 추가 학습하는 것이다.

총 추가 학습:

```text
5 configs x 2 seeds = 10 full trainings
```

| Architecture | WRN-28-10 dropout 0.3 |
| Epochs | 350 |
| Batch size | 128 |
| LR schedule | MultiStep, milestones `[150, 250]`, gamma `0.1` |
| OOD datasets | CIFAR-100, TinyImageNet, SVHN, MNIST |
| Feature layer | penultimate feature |

| Score convention | higher = more ID-like, ID label = 1, OOD label = 0 |

### 4.0.1 Adam weight decay 선택 판단

시간 제약 때문에 Adam은 `wd=0`을 seed1/seed2 반복에서 제외하고, `adam_lr1e-3_wd1e-4`를 regularized Adam 대표로 seed1/seed2 반복한다.

이유:

- `wd=0`만 반복하면 Adam 결과가 no-weight-decay artifact라는 비판을 받을 수 있다.
- `wd=1e-4`는 seed0에서 ID accuracy가 Adam wd0과 비슷하고, regularized Adam 대표로 해석하기 더 안전하다.
- `adam_lr1e-3_wd0`은 기존 seed0 bundle에는 남겨 supplementary 또는 Q&A용 no-WD control로만 사용한다.
- 포스터 main 3-seed table에는 seed1/2 반복이 있는 `adam_lr1e-3_wd1e-4`만 Adam representative로 넣는다.

해석 규칙:

```text
Do not conclude from seed0 that Adam weight decay has no effect.
Use adam_lr1e-3_wd1e-4 as the 3-seed Adam representative.
Use adam_lr1e-3_wd0 only as a seed0 no-WD supplementary control unless additional seed1/2 runs are later approved.
```

추가 여유가 있으면 `adam_lr1e-3_wd0` seed1/2 반복을 되살리거나, `adam_lr1e-3_wd5e-4`를 seed0 practical completion에 넣어 Adam `lr=1e-3`에서 `wd=0,1e-4,5e-4` 축을 보강한다. 단, seed1/seed2 반복이 없는 cell은 main 3-seed table에는 넣지 않는다.

### 4.1 Practical seed0 grid completion 후보

시간이 남을 때만 아래 cell을 seed0에서 추가한다. 이것은 selected 5 configs의 seed1/seed2 반복보다 뒤에 둔다.

현재 practical 27-run grid 중 기존 15-run bundle에 없는 cell:

| Optimizer | Missing practical seed0 cells |
|---|---|
| SGD | `(0.05,2e-4)`, `(0.05,1e-3)`, `(0.2,2e-4)`, `(0.2,1e-3)` |
| Adam | `(3e-4,1e-4)`, `(3e-4,5e-4)`, `(1e-3,5e-4)`, `(3e-3,0)`, `(3e-3,5e-4)` |
| AdamW | `(1e-3,1e-4)`, `(1e-3,1e-3)`, `(3e-3,1e-4)`, `(3e-3,1e-3)` |

총 13 runs다. 기존 bundle의 `adam_lr5e-3_wd5e-4_anchor`는 useful anchor지만 practical 27-run grid의 정규 cell은 아니다.

시간이 애매하면 13개를 전부 돌리지 말고 아래 6개를 먼저 돌린다.

| Priority | Config | 이유 |
|---|---|---|
| 1 | Adam `(1e-3,5e-4)` | Adam `1e-3` 축에서 WD 효과를 완성 |
| 2 | Adam `(3e-3,0)` | Adam high-LR에서 WD 없는 대조군 |
| 3 | Adam `(3e-3,5e-4)` | Adam high-LR에서 stronger WD 대조군 |
| 4 | AdamW `(3e-3,1e-4)` | AdamW `3e-3` 축에서 WD 효과 확인 |
| 5 | AdamW `(3e-3,1e-3)` | AdamW `3e-3` 축에서 stronger WD 확인 |
| 6 | SGD `(0.2,1e-3)` | SGD high-LR/strong-WD corner 확인 |

이 6개는 main table 후보가 아니라 seed0 response surface/heatmap 보강용이다. 이 중 새로 좋은 후보가 나오면 포스터 main result에 넣기 전에 seed1/seed2 반복을 추가 승인받는다.

실행 전 확인:

- seed0 YAML을 복사해 seed1/seed2 YAML을 만든다.
- `run.seed`, config 파일명, run tag만 바꾸고 optimizer/LR/WD/scheduler/data/eval detector 설정은 바꾸지 않는다.
- 이미 있는 `cifar10_standard-wrn-28-10-dropout03_sgd_350ep_seed1.yaml`, `seed2.yaml`은 `sgd_lr1e-1_wd5e-4_anchor`와 같은 설정인지 launch 전에 확인한다.
