## 0. 이번 수정의 핵심

포스터의 main experiment를 단순한 `SGD vs Adam vs AdamW` 비교에서 **WideResNet-28-10의 LR x weight decay grid-search**로 바꾼다.

새로운 중심 메시지는 다음이다.

> Even among models with similar ID accuracy, LR and weight decay choices can induce different feature geometry and therefore different reliability profiles.

한국어로는 다음처럼 쓴다.

> ID accuracy가 비슷한 모델이라도, optimizer별 LR과 weight decay 조합이 penultimate feature geometry를 다르게 만들고, 그 결과 calibration, logit-OOD, feature-OOD 신뢰성은 서로 다르게 움직일 수 있다.

이 방향이 기존 `SGD/Adam/AdamW matched anchor`보다 나은 이유:

- Adam matched anchor는 ID test accuracy가 87.24%로 낮아서 `same accuracy` 주장의 main evidence로 쓰기 어렵다.
- 반면 0531 seed0 grid-search에는 ID accuracy가 94-95%대인 Adam/AdamW 후보가 있고, 이 후보들에서 raw feature detector와 L2-normalized detector의 차이가 크게 나타난다.
- 따라서 통계학회 포스터는 `optimizer 이름 자체`보다 `LR x WD가 만드는 accuracy-matched reliability profile`을 보여주는 쪽이 더 안전하고 설득력 있다.

## 2. Reference anchors for grid design

이번 grid 후보군은 임의로 만들지 않는다. 아래 네 가지 reference anchor를 사용한다.

| Anchor | 포스터/실험에서 쓰는 역할 |
|---|---|
| WideResNet reference | WRN-28-10 CIFAR setting의 SGD 기준점. 기존 WRN 계열 실험에서 `lr=0.1`, momentum `0.9`, weight decay `5e-4`, batch size `128`가 자연스러운 anchor다. |
| Adam paper | Adam-family LR의 중심값을 `1e-3`로 잡는 근거다. |
| AdamW paper | adaptive optimizer에서 LR과 decoupled weight decay를 분리해 grid로 봐야 한다는 근거다. |
| Optimizer choice matters for NC | optimizer choice와 coupled/decoupled weight decay가 Neural Collapse geometry를 바꾼다는 근거다. 단, OOD detector 변화의 직접 근거로 쓰지 않는다. |

중요한 boundary:

- `Optimizer choice matters for the emergence of Neural Collapse`는 optimizer -> NC/geometry 근거다.
- 이 논문을 Mahalanobis, kNN, DDU degradation의 직접 근거로 쓰지 않는다.
- OOD detector link는 우리 WRN grid와 post-hoc evaluation이 직접 보여야 한다.

## 4. Accuracy-matched analysis rule

Grid-search를 main으로 삼으려면 `same accuracy`를 사후적으로 흐리게 말하면 안 된다. 아래 rule을 미리 정한다.

### Selection rule

1. 각 run의 `best validation accuracy`를 기록한다.
2. OOD와 geometry를 보지 않고, ID validation accuracy만으로 accuracy-matched candidate set을 만든다.
3. 기본 band는 다음 중 하나를 사용한다.

```text
Primary band: best val acc >= 0.945
Tight band:   0.950 <= best val acc <= 0.955
Anchor band:  within 0.5 percentage point of selected AdamW validation-best candidate
```

현재 seed0 결과에서는 `best val acc >= 0.945`가 가장 현실적이다. tight band는 seed1/seed2에서 후보가 너무 적으면 보조 분석으로 내린다.

### Main analysis

Accuracy-matched band 안에서 다음을 비교한다.

- ID test accuracy
- NLL, ECE, T-ECE
- near-OOD logit AUROC
- near-OOD raw Mahalanobis, Mahalanobis-L2
- near-OOD raw kNN, kNN-L2
- GMM-DDU shrinkage 또는 DDU-style GMM feature density
- NC1, InterDist, NC3 cosine alignment
- feature norm statistics
- covariance effective rank, anisotropy, condition number diagnostic

핵심 문장:

```text
Among ID-validation-matched WRN-28-10 models, OOD and calibration reliability metrics vary substantially across optimizer/LR/WD configurations.
```

### seed1/seed2가 생겼을 때

반복 후보에 대해 paired delta를 보고한다.

```text
Delta metric_s = Metric(config A, seed s) - Metric(config B, seed s)
```

주요 paired comparison:

- AdamW validation-best vs SGD anchor
- AdamW anchor vs SGD anchor

## 9. 포스터에서 쓸 문장

### 써도 되는 문장

- In a seed0 WRN-28-10 LR-WD grid, ID-validation-matched configurations show different calibration and OOD reliability profiles.
- Adam/AdamW configurations can retain competitive ID accuracy while raw Mahalanobis and raw kNN scores become much more sensitive than their L2-normalized counterparts.
- This suggests that feature norm and covariance-scale geometry should be reported alongside ID accuracy when evaluating post-hoc feature OOD detectors.
- OOD metrics are not used for hyperparameter selection; they are post-hoc diagnostics.
- The current result is seed0-only and will be extended on the department GPU server with seed1/seed2 repetitions.

### 피해야 할 문장

- SGD, Adam, AdamW have the same accuracy but different OOD reliability.
- AdamW feature OOD fails.
- Neural Collapse weakening alone causes Mahalanobis collapse.
- Weight decay reduction solves Mahalanobis collapse.
- kNN is local, so it is free from feature norm effects.
- Mahalanobis-L2 is a full reproduction of Mahalanobis++.
- Seed0 proves optimizer effects are consistent.
