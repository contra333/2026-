    {\WantedLabelFont\color{WantedAccent}Calibration\par}
    \vspace{0.8mm}
    {\fontsize{12.8pt}{16.5pt}\selectfont
    \[
    \begin{aligned}
    \mathrm{acc}(B)&=\frac{1}{|B|}\sum_{i\in B}\mathbf{1}(\hat y_i=y_i),\\
    \mathrm{conf}(B)&=\frac{1}{|B|}\sum_{i\in B}\max_k p_i(k)
    \end{aligned}
    \]
    \[
    \mathrm{ECE}=\sum_b \frac{|B_b|}{n}\,
    |\mathrm{acc}(B_b)-\mathrm{conf}(B_b)|
    \]}

    ECE summarizes the confidence-accuracy gap across confidence bins.}

\newcommand{\OptimizerMechanismSketch}{%
  \vspace{0.8mm}
  {\WantedLabelFont\color{WantedAccent}Feature distribution view\par}
  \vspace{0.6mm}
  {\fontsize{17.2pt}{23pt}\selectfont\color{WantedText}\RaggedRight
  마지막 표현을 $H=h_\theta(X)$로 보면, optimizer는 각 class 조건부분포
  $H\mid Y=k$의 위치와 산포를 만드는 implicit bias로 작용한다.\par}
  \vspace{0.6mm}
  {\fontsize{18pt}{23pt}\selectfont
  \[
  H\mid Y=k:\quad
  \mu_k=\mathbb{E}[H\mid Y=k],\qquad
  \Sigma_k=\operatorname{Var}(H\mid Y=k)
  \]}
  \vspace{-2mm}
  {\fontsize{16.4pt}{21pt}\selectfont\color{WantedText}\RaggedRight
  Feature detectors see within-class dispersion, covariance scale/anisotropy, and between-class separation.\par}
  \vspace{2.5mm}
  {\WantedLabelFont\color{WantedAccent}Weight-decay coupling mechanism\par}
  \vspace{0.6mm}
  {\fontsize{18pt}{23pt}\selectfont
  \[
  z=W h_\theta(x),\quad
  s_t=W_t^\top\mathbf{1}_K,\quad
  a_t=\frac{1}{K}\|s_t\|_2^2,\quad
  (\nabla_W L_{\mathrm{CE}})^\top\mathbf{1}_K=0
  \]}
  \vspace{-2.5mm}
  \begin{minipage}[t]{0.49\linewidth}
    {\color{WantedPrimary}\rule{\linewidth}{0.55mm}}\par
    \vspace{1mm}
    {\PaperHeaderMetaFace\fontsize{15.4pt}{19pt}\selectfont\bfseries\color{WantedInk}SGD/L2: centering contraction\par}
    \vspace{-1.5mm}
    {\fontsize{18pt}{23pt}\selectfont
    \[
    \begin{aligned}
    s_{t+1}&=(1-\eta\lambda)s_t\\
    a_{t+1}&\approx(1-\eta\lambda)^2a_t
    \end{aligned}
    \]}
    \vspace{-1mm}
    {\fontsize{14.6pt}{19pt}\selectfont\color{WantedText}\RaggedRight CE gradient row-sum이 0이므로 class-direction centering statistic이 수축한다.\par}
  \end{minipage}%
  \hfill
  \begin{minipage}[t]{0.49\linewidth}
    {\color{WantedAccent}\rule{\linewidth}{0.55mm}}\par
    \vspace{1mm}
    {\PaperHeaderMetaFace\fontsize{15.4pt}{19pt}\selectfont\bfseries\color{WantedInk}Adam/L2 vs AdamW: distribution path split\par}
    \vspace{-1.5mm}
    {\fontsize{18pt}{23pt}\selectfont
    \[
    \begin{aligned}
    \text{Adam/L2: }& D_t(\nabla L+\lambda W_t)\\
    \text{AdamW: }& D_t\nabla L\ +\ \text{outside shrinkage}\\
    &(D_t\nabla L)^\top\mathbf{1}_K\not\equiv 0
    \end{aligned}
    \]}
    \vspace{-1mm}
    {\fontsize{14.6pt}{19pt}\selectfont\color{WantedText}\RaggedRight 좌표별 scaling이 classifier centering과 feature 분포 경로를 바꿀 수 있다.\par}
  \end{minipage}\par
  \vspace{4.2mm}
}

  \PaperPlainAbstract{%
    ID accuracy는 정답률을 요약하지만, confidence calibration과 distribution-shift robustness를 보장하지 않는다.
    우리는 CIFAR-10 WRN-28-10을 SGD, Adam, AdamW와 LR–weight decay grid로 학습하고,
    ID validation accuracy만으로 선택한 후보들의 calibration, post-hoc OOD detection, feature geometry를 진단한다.
    Seed0 diagnostic draft는 비슷한 accuracy band 안에서도 raw feature OOD reliability가 갈라질 수 있으며,
    L2-normalized controls가 그 차이를 feature norm/covariance-scale geometry와 연결해 볼 수 있음을 시사한다.
  }

  \PaperConceptSection{Introduction: Why Accuracy Is Not Reliability}{%
    \PaperClaim{Accuracy summarizes correctness; reliability asks more.}
    \PaperBullet{ID accuracy는 모델이 test distribution에서 정답을 얼마나 자주 맞히는지를 요약한다.}
    \PaperBullet{실제 배포 reliability는 confidence가 믿을 만한지, distribution-shift input을 정상 입력처럼 받아들이지 않는지까지 함께 확인해야 한다.}
    \PaperBullet{비슷한 ID accuracy라도 optimizer와 LR–weight decay 선택이 penultimate feature geometry를 다르게 만들면 post-hoc detector의 score landscape도 달라질 수 있다.}
    \PaperBullet{따라서 optimizer를 단순한 training speed 선택이 아니라 calibration과 feature-based OOD reliability를 바꿀 수 있는 실험 요인으로 다룬다.}
    \PaperQuestionFocus{비슷한 Accuracy라도 optimizer가 만든 feature geometry가 모델의 신뢰성에 어떤 영향을 미치는가?}
  }

  \PaperConceptSection{Reliability Failure: Miscalibration and OOD Acceptance}{%
    \PaperClaim{신뢰성 실패는 높은 confidence를 믿고 넘기거나 OOD 입력을 정상 입력처럼 넘기는 순간 downstream decision을 흔든다.}
    \PaperBullet{Confidence는 보통 모델이 선택한 class의 softmax probability이고, actual accuracy는 비슷한 confidence bin 안에서 실제로 정답이었던 비율이다.}
    \PaperBullet{Confidence와 actual accuracy가 크게 다르면 miscalibration이며, confidence-threshold 기반 승인/보류 결정이 불안정해진다.}
    \PaperBullet{Post-hoc OOD detector는 score $s(x)$로 ID sample에는 높은 ID-like score를, OOD sample에는 낮은 score를 주어야 한다.}
    \PaperBullet{OOD sample이 높은 ID-like score를 받으면, 지원하지 않는 입력도 정상 class prediction으로 downstream decision에 넘어갈 수 있다.}
