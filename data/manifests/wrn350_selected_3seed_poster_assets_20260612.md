## Evidence Boundary

- Selection uses ID validation accuracy only.
- Calibration, OOD, and feature geometry metrics are post-hoc diagnostics.
- Poster table values and figure error bars are seed0/1/2 mean +/- sample standard deviation.
- The main OOD figure keeps CIFAR-100 and TinyImageNet separate; it does not average across OOD datasets.
- OOD score convention is `higher score = more ID-like`, `ID label = 1`, `OOD label = 0`.
- `gmm_ddu_*` metrics must be described as `DDU-style GMM feature density` diagnostics, not full DDU reproduction.
- The current poster uses `poster/poster_style.tex` as the active TeX style file.
  The retired design harness is archived and is not an active dependency.
